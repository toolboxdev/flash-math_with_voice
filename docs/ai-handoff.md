# AI Handoff

このファイルは、別チャットのAIが最初に読んでプロジェクトの現在地を把握するための要約です。
テンプレート導入直後は薄くて問題ありません。作業が進むたびに、必要な差分だけ追記・更新します。

## プロジェクト概要

- ブラウザで動く「フラッシュ たしざん ひきざん」アプリ。
- GitHubリポジトリ `toolboxdev/flash-math_with_voice` を、このフォルダーでローカル開発する。
- 現在のゴールは、ユーザーが希望する機能追加・修正をローカルで実装し、ブラウザで確認できる状態を保つこと。

## 主要ファイル

- `index.html`: HTML・CSS・JavaScriptをまとめたアプリ本体。
- `README.md`: 現時点では未作成。
- `CHANGELOG.md`: ユーザー向けの変更履歴。
- `docs/decisions.md`: 長期的な判断や方針。
- `docs/reference-log.md`: ユーザー提示の重要な原文要件。
- `docs/ai-context-workflow.md`: 文脈管理とチャットログ出力の手順。

## 現在の実装状況

- 2026-08-01、GitHubの `origin/main` をローカルの `main` に取り込んだ。
- 取り込み時点のGitHub側の管理対象ファイルは `index.html` 1ファイル。
- `index.html` は依存パッケージを必要としない単一HTML構成。
- `python -m http.server 8765 --bind 127.0.0.1` で配信し、`http://127.0.0.1:8765/` の初期画面が表示されることを確認済み。
- 表示確認時、ブラウザの警告・エラーは検出されなかった。
- 2026-08-01、正解時は0.7秒後に次の問題を自動出題し、不正解時だけ「つぎ」ボタンを使うように変更した。
- 2026-08-01、背景と各ボックスを薄いクリーム色に統一して茶系の枠線を付け、通常ボタンを淡い水色、選択中を少し濃い水色、主要ボタンを青色へ変更した。
- 2026-08-01、キーパッドに `touch-action: manipulation` を指定し、同じ数字の連続入力で起きるダブルタップ拡大を抑止した。数字の連続入力とピンチ拡大は維持する。
- 2026-08-01、作業ブランチ `agent/flash-math-ui-fixes` をGitHubへプッシュし、ドラフトPR #8を `main` 向けに作成した。最初の実装コミットは `559673c`（`操作性と画面配色を改善`）。

## 都度保存の運用

| 内容 | 保存先 |
| --- | --- |
| ユーザー向けの機能追加・仕様変更・バグ修正 | `CHANGELOG.md` |
| 別チャットのAIに引き継ぐ現在地・実装状況・次の作業 | `docs/ai-handoff.md` |
| 長期的な設計判断・運用方針・採用/不採用の理由 | `docs/decisions.md` |
| ユーザーが提示した重要な原文要件・制約・参考情報 | `docs/reference-log.md` |

| 人間が読む詳細まとめ | `docs/chat-summary-detailed.html` |

保存先やバージョン更新の判断が曖昧な場合は、AIがユーザーに確認する。
